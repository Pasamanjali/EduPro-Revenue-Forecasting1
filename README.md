#  Edupro Revenue Forecasting

##   Project Overview
Edupro Revenue Forecasting is a Machine Learning web application that predicts the number of students likey to enroll in an online course based pm course details such as category,price,rating,duration, and marketing spend.  it also estimates the expected revenue.

##  features
- Predict course demand
- Forcast expected revenue 
- User-friendly flask web application
- Machine Learing model using Scikit-learn
- Responsive HTML and CSS interface

## Technologies Used
- Python
- Flask
- Pandas
- numpy
- Scikit-learn
- HTML
- CSS
- Joblib

## How to Run

1.Clone the repository
2.Install requirements

'''
pip install -r requirements.txt
''

3.Train the model

'''
python train_model.py
'''

4.Run the flask application

'''
python app.py
'''

5.Open your browser

'''
https://127.0.0.1:5000/
'''
